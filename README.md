# marketmove_app

**App móvil para control simple de ventas, gastos y stock**  
Proyecto desarrollado para MarketMove S.L.

## Descripción
Aplicación móvil multiplataforma (Flutter) que permite a pequeños comercios:
- Registrar ventas diarias.
- Registrar gastos.
- Añadir y gestionar productos y stock.
- Visualizar un panel con balance (ganancias - gastos).
